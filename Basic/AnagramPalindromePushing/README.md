<h2><a href="#">Anagram PalindromePushing...</a></h2>
<h3>Difficulty: Basic</h3><hr>
<p><span style="font-size: 18px;">Given a string <strong>s</strong>, determine whether its characters can be rearranged to form a palindrome. </span><span style="font-size: 18px;">Return <strong>true</strong> if it is possible to rearrange the string into a palindrome; otherwise, return <strong>false</strong>.</span></p>
<p><span style="font-size: 18px;"><strong>Examples</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "baba"
<strong>Output:</strong> true
<strong>Explanation</strong>: Can be rearranged to form a palindrome "abba" </span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "geeksogeeks"
<strong>Output:</strong> true
<strong>Explanation</strong>: The characters of the string can be rearranged to form the palindrome "geeksoskeeg".
</span></pre>
<pre><span style="font-size: 18px;"><strong>Input</strong>: s = "geeksforgeeks"
<strong>Output:</strong> false
<strong>Explanation</strong>: The given string can't be converted into a palindrome.</span>
</pre>
<p><span style="font-size: 18px;"><strong style="font-size: 18px;">Constraints:</strong><br><span style="font-size: 18px;"><span style="font-size: 18px;">1 ≤ s.length ≤ 10</span><sup style="font-size: 18px;">6</sup><br><span style="font-size: 14pt;">s consists of only&nbsp;</span></span></span><span style="font-size: 14pt;">lowercase English letters.</span></p>
