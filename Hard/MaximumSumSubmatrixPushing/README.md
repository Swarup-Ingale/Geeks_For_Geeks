<h2><a href="#">Maximum Sum SubmatrixPushing...</a></h2>
<h3>Difficulty: Hard</h3><hr>
<p><span style="font-size: 14pt;">Given a 2D matrix <strong>mat[][]</strong> with dimensions n×m. Find the maximum possible <strong>sum</strong> of any <strong>submatrix </strong>within the given matrix.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>mat[][] = [[1, 2, -1, -4, -20], [-8, -3, 4, 2, 1], [3, 8, 10, 1, 3], [-4, -1, 1, 7, -6]]
<strong>Output: </strong>29
<strong>Explanation: </strong>The matrix is as follows and the green rectangle denotes the maximum sum rectangle which is equal to 29.
