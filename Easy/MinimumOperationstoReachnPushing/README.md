<h2><a href="#">Minimum Operations to Reach nPushing...</a></h2>
<h3>Difficulty: Easy</h3><hr>
<p><span style="font-size: 18px;">Given a number <strong>n</strong>. Find the minimum number of operations required to reach n starting from 0. </span></p><p><span style="font-size: 18px;">You have two<strong> </strong>operations available:</span></p><ul><li><span style="font-size: 18px;">Double the number </span></li><li><span style="font-size: 18px;">Add one to the number</span></li></ul><p><span style="font-size: 18px;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18px;"><strong>Input: </strong>n = 8
<strong>Output:</strong> 4
<strong>Explanation:</strong> 0 + 1 = 1 --&gt; 1 + 1 = 2 --&gt; 2 * 2 = 4 --&gt; 4 * 2 = 8.
</span></pre><pre><span style="font-size: 18px;"><strong>Input:</strong> n = 7
<strong>Output:</strong> 5
<strong>Explanation:</strong> 0 + 1 = 1 --&gt; 1 + 1 = 2 --&gt; 1 + 2 = 3 --&gt; 3 * 2 = 6 --&gt; 6 + 1 = 7.</span></pre>
