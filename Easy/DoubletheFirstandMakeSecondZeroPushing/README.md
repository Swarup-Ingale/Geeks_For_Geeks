<h2><a href="#">Double the First and Make Second ZeroPushing...</a></h2>
<h3>Difficulty: Easy</h3><hr>
<p><span style="font-size: 14pt;">Given an array <strong>arr[]</strong> of size <strong>n</strong>, modify it such that if two adjacent elements are equal and non-zero, double the first element and replace the second element with 0. After processing the entire array, move all 0s to the end while maintaining the relative order of the non-zero elements. Return the modified array.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[] = [2, 2, 0, 4, 0, 8] <br><strong>Output:</strong> [4, 4, 8, 0, 0, 0] <br><strong>Explanation: </strong></span><span style="font-size: 18px;">At index 0 and 1 both the elements are the same. So, we change the element at index 0 to 4 and the element at index 1 is 0 then shift all the zeros to the end of the array [4,4,8,0,0,0].</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[] = [0, 2, 2, 2, 0, 6, 6, 0, 0, 8]<strong>&nbsp;<br>Output:</strong> [4, 2, 12, 8, 0, 0, 0, 0, 0, 0]<br><strong>Explanation: </strong></span><span style="font-size: 18px;">Elements at indices 1 and 2 are equal and non-zero, so they are replaced by 4 and 0. Similarly, elements at indices 5 and 6 are replaced by 12 and 0. After moving all 0s to the end, the final array becomes [4, 2, 12, 8, 0, 0, 0, 0, 0, 0].</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ arr.size() ≤ 10<sup>5<br></sup>0 ≤ arr[i] ≤ 10<sup>6</sup><sup><br></sup></span></p>
