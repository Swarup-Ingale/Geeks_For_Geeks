<h2><a href="#">K Liters using Given VesselsPushing...</a></h2>
<h3>Difficulty: Easy</h3><hr>
<p class="PDq2pG_selectionAnchorContainer" dir="auto" data-start="321" data-end="500"><span style="font-size: 14pt;">Given an array <strong>arr[]</strong> containing the capacities of available vessels and an integer <strong>k</strong>, find if it is possible to obtain exactly k liters of water using the vessels. </span><span style="font-size: 14pt;">Each vessel can be used any number of times, but whenever a vessel is used, its entire capacity must be added. Return true if exactly k liters can be obtained; otherwise, return false.</span></p><p class="PDq2pG_selectionAnchorContainer" dir="auto" data-start="321" data-end="500"><strong><span style="font-size: 14pt;">Examples:</span></strong></p><pre><span style="font-size: 14pt;"><strong>Input:</strong> arr[] = [6, 3, 4, 2, 1], k = 20</span><br><span style="font-size: 14pt;"><strong>Output:</strong> true</span><br><span style="font-size: 14pt;"><strong>Explanation: </strong></span><span style="font-size: 18.6667px;">Use the 6-liter vessel 3 times and the 2-liter vessel once: 6 + 6 + 6 + 2 = 20.</span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> arr[] = [2, 4, 3], k = 15</span><br><span style="font-size: 14pt;"><strong>Output:</strong> true</span><br><span style="font-size: 14pt;"><strong>Explanation: </strong></span><span style="font-size: 14pt;">Use the 3-liter vessel 5 times: 3 + 3 + 3 + 3 + 3 = 15.</span></pre>
