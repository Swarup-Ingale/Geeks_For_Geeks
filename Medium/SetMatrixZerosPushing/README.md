<h2><a href="#">Set Matrix ZerosPushing...</a></h2>
<h3>Difficulty: Medium</h3><hr>
<p><span style="font-size: 18px;">Given a 2D matrix <strong>mat[][]</strong> of size </span><span style="font-size: 18px;"><strong>n x m</strong>. </span><span style="font-size: 18px;">Modify the matrix such that if <strong>mat[i][j]</strong> is 0, all the elements in the<strong> </strong></span><span style="font-size: 18px;">i-th<strong> </strong>row and </span><span style="font-size: 18px;">j-th column are set to 0.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1, -1, 1], [-1, 0, 1], [1, -1, 1]]<strong style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif; white-space: normal;">&nbsp; &nbsp;&nbsp;</strong>
<strong>Output: </strong>[[1, 0, 1], [0, 0, 0], [1, 0, 1]]   
<strong>Explanation:</strong> </span><span style="font-size: 18px;">mat[1][1] = 0, so all elements in row 1 and column 1 are updated to zeroes.<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/874880/Web/Other/blobid1_1782295129.png" alt=""><br></span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[0, 1, 2, 0], [1, 2, 6, 2], [1, 3, 1, 8]]<strong style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif; white-space: normal;">&nbsp;</strong></span><span style="font-size: 18px;"> &nbsp;  <br><strong>Output:</strong> [[0, 0, 0, 0], [0, 2, 6, 0], [0, 3, 1, 0]]<strong style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif; white-space: normal;">&nbsp;&nbsp;</strong><br></span><span style="font-size: 18px;"><strong>Explanation:</strong> </span><span style="font-size: 18px;">mat[0][0] and mat[0][3] are 0s, so all elements in row 0, column 0 and column 3 are updated to zeroes.<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/874880/Web/Other/blobid2_1782295129.png" alt=""></span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ n, </span><span style="font-size: 18px;">m</span><span style="font-size: 18px;"> ≤ 500</span><sup><br></sup><span style="font-size: 18px;">- 2<sup>31</sup> ≤ mat[i][j] ≤ 2<sup>31</sup> - 1</span></p>
