<h2><a href="#">Longest Subarray Sum Divisible by KPushing...</a></h2>
<h3>Difficulty: Medium</h3><hr>
<p><span style="font-size: 14pt;">Given an array <strong>arr[]</strong> and a positive integer <strong>k</strong>, find the length of the longest<strong> </strong>subarray with the sum of the elements divisible<strong> </strong>by k.</span></p><p><span style="font-size: 14pt;"><strong>Note:&nbsp;</strong>If there is no subarray with sum divisible by k, then return 0.<br></span></p><p><span style="font-size: 14pt;"><strong>Examples :</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [2, 7, 6, 1, 4, 5], k = 3
<strong>Output:</strong> 4
<strong>Explanation: </strong>The subarray [7, 6, 1, 4] has sum = 18, which is divisible by 3.</span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [-2, 2, -5, 12, -11, -1, 7], k = 3
<strong>Output:</strong> 5
<strong>Explanation: </strong>The subarray [2, -5, 12, -11, -1] has sum = -3, which is divisible by 3.<br></span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [1, 2, -2], k = 2
<strong>Output:</strong> 2
<strong>Explanation: </strong>The subarray is [2, -2] has sum = 0, which is divisible by 2.</span></pre>
